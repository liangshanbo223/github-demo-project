# Antigravity Hub (反重力控制枢纽)

一个具有未来科技感的现代 Web 概念主页。本项目采用极致的视觉美学设计，展示了现代网页设计的最佳实践，包括玻璃态效果（Glassmorphism）、动态渐变背景以及微交互动画。

## 🌟 视觉设计亮点

- **暗黑科技风**：精心调配的深色调背景，搭配霓虹蓝与紫色的渐变发光效果。
- **玻璃态效果 (Glassmorphism)**：使用 CSS `backdrop-filter` 打造半透明高斯模糊面板，质感通透。
- **微交互动画**：按钮、卡片在悬停时拥有平滑的缩放、阴影和发光效果。
- **现代排版**：引入 Google 字体 `Outfit` 和 `Inter`，字形极具现代感和未来科技气息。

## 🚀 快速开始

1. **本地预览**：
   直接使用浏览器打开 `index.html` 即可预览华丽效果。
   
2. **开发模式**：
   如果您在此基础上进行扩展，推荐使用任何本地静态服务器（如 VS Code 的 Live Server 插件）以获得最佳的 `backdrop-filter` 渲染体验。

- **骨架**：HTML5 语义化标签

- **字体**：Google Fonts (Outfit & Inter)
- **图标**：Font Awesome (通过 CDN 引入)
